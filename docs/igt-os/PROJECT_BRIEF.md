# PROJECT BRIEF

IGT OS is the internal operating command center of Invictus Global Tech (performance marketing / creative / technology agency).
Goal: the CEO manages exceptions, decisions and opportunities instead of chasing tasks, WhatsApp, Sheets, campaign numbers and team status.
Operating model: activity -> structured state -> automatic monitoring -> exceptions -> owner -> action -> CEO only when necessary.

Stack: Next.js 16 (frontend) + Express/Postgres (backend, cookie JWT). Monorepo workspaces `frontend/`, `backend/`.
Principles: server-side authorization; provenance on every number; no fabricated integrations; additive migrations only; tests for every fixed bug.
